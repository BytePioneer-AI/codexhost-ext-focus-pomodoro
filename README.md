# Focus Pomodoro / 专注番茄钟

![Focus Pomodoro workspace page](assets/pomodoro-workspace.png)

## English

Focus Pomodoro adds a floating timer widget and a full workspace page to CodexHost Desktop and Web. Start or pause without leaving a conversation, switch between focus, short break, and long break, or use the workspace page to adjust the presets. Both views share the countdown, task note, and daily completion count in the same browser context. Timer state survives a refresh; the extension needs no backend.

**Install:** Download `focus-pomodoro.zip` from the [release](https://github.com/BytePioneer-AI/codexhost-ext-focus-pomodoro/releases/tag/v1.1.0), import and enable it in the CodexHost Extensions Center, then open the sidebar page or use the floating timer. Use a CodexHost build that supports unified v2 extensions with pages and widgets.

## 简体中文

专注番茄钟为 CodexHost Desktop 和 Web 提供悬浮计时组件与独立工作区页面。无需离开对话即可开始或暂停计时，切换专注、短休和长休，或在工作区页面调整预设时长。同一浏览器上下文中的两个视图共享倒计时、任务备注和每日完成数，刷新后仍可继续计时，无需后台进程。

**安装：** 从 [Release](https://github.com/BytePioneer-AI/codexhost-ext-focus-pomodoro/releases/tag/v1.1.0) 下载 `focus-pomodoro.zip`，在 CodexHost 插件中心导入并启用，然后打开侧边栏页面或使用悬浮计时器。需要支持统一 v2 扩展页面与悬浮组件的 CodexHost 版本。
