# Focus Pomodoro / 专注番茄钟

![Focus Pomodoro workspace page](assets/pomodoro-workspace.png)

## English

Focus Pomodoro adds a floating timer widget and a full workspace page to CodexHost Desktop and Web. Start or pause without leaving a conversation, switch between focus, short break, and long break, or use the workspace page to adjust presets and review focus history. When a round finishes, a centered completion celebration animation appears with a gentle optional chime and one-click transition to your next break or focus round. Timer state, task notes, and completed round history persist to shared Host storage (`api.storage`), keeping Codex Desktop, local Web, and remote CH Web in sync with zero backend process.

**Install:** Download `focus-pomodoro.zip` from the [latest release](https://github.com/BytePioneer-AI/codexhost-ext-focus-pomodoro/releases), import and enable it in the CodexHost Extensions Center, then open the sidebar page or use the floating timer. Use a CodexHost build that supports unified v2 extensions with pages and widgets.

## 简体中文

专注番茄钟为 CodexHost Desktop 和 Web 提供悬浮计时组件与独立工作区页面。无需离开对话即可开始或暂停计时，切换专注、短休和长休，或在工作区页面调整预设时长、查看专注记录与近 7 天统计。每轮倒计时结束时，会在屏幕中央展示柔和的完成庆祝动画与可选轻柔提示音，并支持一键进入建议的休息或下一轮专注。倒计时状态、任务备注与历史完成记录均持久化在共享 Host 存储（`api.storage`）中，本机 Desktop、本机 Web 与远程 CH Web 实时同步，无需后台进程。

**安装：** 从 [Releases](https://github.com/BytePioneer-AI/codexhost-ext-focus-pomodoro/releases) 下载 `focus-pomodoro.zip`，在 CodexHost 插件中心导入并启用，然后打开侧边栏页面或使用悬浮计时器。需要支持统一 v2 扩展页面与悬浮组件的 CodexHost 版本。
